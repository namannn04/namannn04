### Featured Projects

**[Presora](https://github.com/namannn04)** — Prescription safety platform for hospitals, doctors & patients
`Next.js` `FastAPI` `PostgreSQL` `SQLAlchemy` `Redis` `Celery` `Keycloak` `Docker`
- Medicine intelligence engine over a 250K+ dataset using Postgres trigram search + fuzzy matching for real-time autocomplete
- TOTP-based MFA and consent-driven patient record access for healthcare-grade security
- Patient health records, medication history, allergy tracking, and prescription workflows

**[Launchly](https://github.com/namannn04)** — Full-stack deployment platform (Vercel-style, self-hosted)
`Next.js` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Node.js`
- Async deployment pipeline with Redis + BullMQ workers for clone → install → build → run
- Runtime detection for Next.js, Node.js, and static projects with health checks and live logs
- Subdomain-based routing and a dashboard for deployment status and live URLs

**Multiplayer Card Game Platform** — Real-time multiplayer games (Old Maid, Seep) inspired by CrazyGames
`Socket.IO` `PostgreSQL` `Drizzle ORM` `Next.js`
- Real-time gameplay over Socket.IO with a shared profile/stats system across games
- JSONB-based per-game stats tracking in a single schema, avoiding table sprawl

**[Career Compass](https://github.com/namannn04)** — AI-assisted career guidance platform
`Next.js` `PostgreSQL` `Prisma` `Firebase` `Node.js`
- Roadmaps for 500+ careers with an admin panel for managing registrations and data
- Interactive UI with Framer Motion, profile and pagination features
